Anki Phone Remote

Use your phone as a remote for Anki on your laptop: Show Answer, Again, Hard, Good, Easy and Undo, with big thumb-sized buttons.

Set up (about 3 minutes)

1. Install AnkiConnect in Anki Anki → Tools → Add-ons → Get Add-ons → paste code 2055492159 → restart Anki.
2. Run one line on your laptop Paste into Terminal (Python 3 is already on a Mac): 
curl -sL https://raw.githubusercontent.com/ArafatRais/anki-phone-remote/main/server.py | python3 -
A page opens on your laptop with a QR code. Add -- --pin 1234 at the end to require a PIN.

Prefer double-clicking? Download the zip, unzip, and double-click Start Anki Remote.command (first time: right-click → Open).

3. Scan the QR code with your phone camera Same Wi-Fi as the laptop. Tip: Share → Add to Home Screen for a full-screen app.

No camera handy? Enter the laptop's IP instead:

4. Start a review in Anki Open any deck so the review screen is showing. The phone follows along.

Why isn't the remote hosted on this page?

Browsers refuse to let an https page (like GitHub Pages) talk to a plain http device on your home network. So the remote page is served by the small script on your laptop, and this page is just the guide and launcher. Nothing you do in Anki ever leaves your local network.
